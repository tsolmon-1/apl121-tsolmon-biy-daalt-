"C гаралт" баганыг `gcc`-ээр компайл хийж ажиллуулан шалгасан. "Flowgorithm гаралт" баганыг `quest.fprg`-ийг Run хийж өөрөө бөглөнө.

## №1 тестийн гар тооцоо

- Нийт цаг = 8+8+8+8+8+4+0 = 44
- Энгийн = 40, илүү = 4
- Цалин = 40×10000 + 4×10000×1.5 = 460000
- Суутгал = 460000×10÷100 = 46000
- Гарт = 460000 − 46000 = 414000
