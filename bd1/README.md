# APL121 · Бие даалт №1 — Долоо хоногийн цалингийн тооцоо

## Сэдэв

Цагийн хөлсөөр ажилладаг хүний долоо хоногийн цалинг тооцно. Хэрэглэгч цагийн хөлс, суутгалын хувь, 7 өдрийн ажилласан цагийг оруулна. Программ өдөр бүрийн хүснэгт хэвлэж, энгийн ба илүү цаг, нийт цалин, суутгал, гарт олгох дүнг гаргаад, хамгийн олон цаг ажилласан өдрийг олно.

## Миний тогтоосон тоон дүрэм

| Дүрэм | Утга |
|---|---|
| Цагийн хөлс | 1000 – 200000 төгрөг |
| Суутгал | 0 – 50 % |
| Нэг өдрийн цаг | 0 – 16 |
| Энгийн цаг | 7 хоногт 40 цаг хүртэл |
| Илүү цагийн үржвэр | 1.5 |
| Өдрийн төрөл | 0 цаг = Amralt, 8 хүртэл = Engiin, 8-аас их = Urt |

*Хичээлийн загвар тооцоо; хууль, бодит байгууллагын журам биш.*

## Ажиллуулах

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o tsalin.exe
./tsalin.exe
```

Жишээ: `10000`, `10`, дараа нь `8 8 8 8 8 4 0` → 44 цаг, цалин 460000, суутгал 46000, гарт 414000.

## 7 шаардлага хаана байна вэ?

| # | Шаардлага | `main.c` | Flowgorithm |
|---|---|---|---|
| 1 | Оролт/гаралт | 3 `scanf` (хөлс, хувь, өдрийн цаг), цэгцтэй `printf` | 3 Input, Output |
| 2 | Арифметик + логик | цалингийн томьёо; `\|\|` (хүрээ), `&&` (өдрийн төрөл) | `or`, `and` |
| 3 | `else-if` шат | `Amralt / Engiin / Urt` ангилал | хоёр шатлалт If |
| 4 | Давталт, хүснэгт (7 мөр) | `for` + `%-6d %-10s %6.2f %12.2f` | For |
| 5 | Дэд алгоритм | `main` дотор бичсэн (функц 10-р долоо хоногт) | `ShowRules` Function, `Main`-аас Call |
| 6 | Хайлт | хамгийн их цагтай өдрийг давталтаар хайна | If давталт дотор |
| 7 | Оролтын шалгалт | `do-while` | Do |
