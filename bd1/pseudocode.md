# Псевдокод — долоо хоногийн цалингийн тооцоо

1. Эхлэх.
2. `ShowRules` дэд алгоритмыг дуудаж дүрмийг харуулах.
3. `niitTsag = 0`, `hamgiinTsag = 0`, `hamgiinOdor = 1` гэж эхлүүлэх.
4. Цагийн хөлсийг оруулах. 1000-аас бага **эсвэл** 200000-аас их бол алдаа хэлж дахин асуух.
5. Суутгалын хувийг оруулах. 0-ээс бага **эсвэл** 50-аас их бол дахин асуух.
6. Хүснэгтийн толгойг хэвлэх.
7. `odor` = 1-ээс 7 хүртэл давтах:
   1. Өдрийн цагийг оруулах. 0-ээс бага **эсвэл** 16-аас их бол дахин асуух.
   2. `niitTsag = niitTsag + tsag`.
   3. Хэрэв `tsag > hamgiinTsag` бол `hamgiinTsag = tsag`, `hamgiinOdor = odor`.
   4. Хэрэв `tsag = 0` бол төрөл = "Amralt"; үгүй бол хэрэв `tsag > 0` **ба** `tsag <= 8` бол "Engiin"; бусад тохиолдолд "Urt".
   5. Хүснэгтийн нэг мөр хэвлэх: өдөр, төрөл, цаг, цаг × цагийн хөлс.
8. Хэрэв `niitTsag > 40` бол `engiinTsag = 40`, `iluuTsag = niitTsag - 40`; үгүй бол `engiinTsag = niitTsag`, `iluuTsag = 0`.
9. `niitTsaling = engiinTsag × tsagiinHuls + iluuTsag × tsagiinHuls × 1.5`.
10. `suutgal = niitTsaling × suutgaliinHuvi ÷ 100`.
11. `garDeer = niitTsaling - suutgal`.
12. Нийт цаг, энгийн/илүү цаг, нийт цалин, суутгал, гарт олгох дүн, хамгийн олон цагтай өдрийг хэвлэх.
13. Төгсөх.

## Миний тогтоосон дүрэм

| Дүрэм | Утга |
|---|---|
| Цагийн хөлс | 1000 – 200000 төгрөг |
| Суутгал | 0 – 50 % |
| Нэг өдрийн цаг | 0 – 16 |
| Энгийн цагийн хязгаар | 7 хоногт 40 цаг |
| Илүү цагийн үржвэр | 1.5 |
| Өдрийн төрөл | 0 цаг = Amralt; 8 хүртэл = Engiin; 8-аас их = Urt |
